# Sales and Profit Analysis Dashboard

## About the Project

This project is a data analysis and visualization dashboard
developed using Microsoft Power BI.

The dashboard explores sales and profit data across
different years, regions, product categories, and customer segments.

## Tools Used

- Microsoft Power BI
- Data Visualization
- Data Analysis
- Business Intelligence


## Key Analysis Areas

- Total Sales and Total Profit
- Yearly Sales and Profit Trends
- Profit by Product
- Profit by Region
- Sales by Region
- Customer Segment Analysis

## Project Goal

The goal of this project is to transform raw data into
meaningful visual insights and support data-driven decision-making.
